# Video Rental System

A Java-based project for managing a DVD rental system. Built using Eclipse, with support for customer, employee, product, and role management.

## Features
- Customer and Employee data management
- Product categories and details
- WebContent interface using JSP/Servlets
- Uses a relational database (JDBC)

## Technologies
- Java
- JSP / Servlets
- JDBC
- Eclipse

## Folder Structure
- `src/` - Source code
- `WebContent/` - Web application files
- `.settings/`, `.classpath`, `.project` - Eclipse project configuration
